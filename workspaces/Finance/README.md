# Finance Workspace

> Synthetic test data only. Nothing in this folder represents actual Synvo
> financial results, employees, vendors, or commitments.

This workspace supports controlled document and spreadsheet-style workflows:

- compare budget, actual spending, and year-end forecast;
- draft a monthly finance summary from structured data;
- check close activities against the documented checklist; and
- propose policy edits without accessing any other workspace.

All amounts in `FY2026-budget.csv` are fictional USD values created for Phase 3
verification.
