# Sales Workspace

> Synthetic test data only. All accounts, opportunities, values, and targets
> are fictional and are not connected to a CRM or real customer relationship.

This workspace supports controlled sales-analysis workflows:

- summarize pipeline coverage and opportunity risk;
- compare quarterly targets with the synthetic pipeline;
- draft an account-review report; and
- improve the sales playbook through approved Markdown edits.

Codex must not interpret this data as authorization to contact anyone or update
an external sales system.
